# pos-harness backend

Full-duplex local speech-to-speech voice agent (VAD/STT/LLM/TTS) with
barge-in, session history, and a browser or CLI client.

See the [repo root README](../README.md) for full setup, usage, and
architecture docs — this file exists only because `pyproject.toml`'s
packaging metadata requires a readme inside this directory.
